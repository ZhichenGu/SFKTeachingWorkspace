### 已识别的代码层问题（待用户决定是否修）
1. index.html 212 KB，其中 185,761 字符是内联 base64 PNG（1603×1670，解码 139 KB），
   **只被两处 `<use href="#template">` 以 190×108 / 178×144 的小视窗裁成 logo 使用**。
   抽成独立小图或 SVG 可把首页降到约 60 KB。gzip 后仍有 140 KB。
2. `render()` 每次 input 都重建两份含 185 KB base64 的 SVG innerHTML（live-paper +
   print-paper）；`textBlock` 逐字 measureText、字号 19→14 共 6 档，content/homework
   上限各 12000 字 → 极端情况单次按键约 17 万次 measureText。
3. 公开写权限是用户明确要求的，但 `delete_lesson` 对 anon 开放 + 硬删除 + 无审计，
   任何拿到页面的人可枚举 UUID 清空全表。
4. 5 个 JS 文件靠隐式全局耦合（state / $ / renderDocument / form / signaturePresent），
   加载顺序敏感；无测试、无 CI；schemaVersion 常量写了但从未校验。
5. 手写/宋体依赖 Kaiti SC、Songti SC，Windows/Android 会回退，跨设备版式会漂。

   导师签名）+ 一行一名学生（第几次课/内容/作业/作业完成）。桌面表格、手机卡片（媒体查询）。
   行操作：沿用上次（按姓名取最近记录、第几次课 +1）、复制上一行、删除；姓名 datalist 联想；
   「批量保存并生成链接」逐份 save+publish，每份复制按钮 + 已复制标记（localStorage 持久），

2. **常用默认值**：导师签名 + 课程类型存 `sfk-defaults-v1`，新建单签/批量自动带入，保存后回写。
3. **自动保存**：单签编辑器防抖 2s 自动保存；**仅当 `!active.signed_at && !active.published`**，
   避免误改已签名记录清空学生签名、或改已发链接的记录使链接失效。`cloud.get()` 现在返回
   `published`（share_token 有效则 true），local 仓库返回 published:false。
4. **字体与签名固化**：`cloud.js compactSignature` 把 text 模式姓名在保存时渲染成小图片固化
   （复用 draw 路径）；index.html 增加 `bodyFont`/`handFont` 单引号字体栈（Noto Serif CJK SC /
   Source Han Serif 兜底），SVG 与 canvas measure 同源，避免换行漂移。

### 关键实现细节（后续维护要记住）
- 跨脚本全局：inline `<script>` 顶层 const/function（state/$/renderDocument/initialRecord/
  blankSignature/signaturePresent/clockText/dateLocal/bodyFont/handFont）供后续 script 访问。
- `workspace.js` 暴露 `window.SFKRepo`（repository 抽象）、`window.SFKBatchDefaults`、
  `window.SFKShowDashboard`，batch.js 依赖它们；脚本顺序 index 内联 → config → cloud →
  sharing → exports → workspace → batch。
- `save()` 会 `if(active.published)result.published=true` 保留 published；generate-share 后置
  `active.published=true`。
- 字体栈用**单引号**包裹 family 名（`const bodyFont="'Songti SC',SimSun,…"`），这样 SVG 属性
  `font-family="${bodyFont}"` 与 canvas `measure.font` 都能正确解析，避免双引号冲突。

## 第三轮：按开发协作 spec 补齐（已实现 + 验证）

   SVG 与 canvas measure 同源。子集用 fonttools 从 24.5MB OTF 裁到 7002 常用字（level-1+level-2 6500
