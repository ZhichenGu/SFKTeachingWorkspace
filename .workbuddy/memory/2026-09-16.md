### 已识别的代码层问题（待用户决定是否修）
1. index.html 212 KB，其中 185,761 字符是内联 base64 PNG（1603×1670，解码 139 KB），
   **只被两处 `<use href="#template">` 以 190×108 / 178×144 的小视窗裁成 logo 使用**。

3. 公开写权限是用户明确要求的，但 `delete_lesson` 对 anon 开放 + 硬删除 + 无审计，
   任何拿到页面的人可枚举 UUID 清空全表。
4. 5 个 JS 文件靠隐式全局耦合（state / $ / renderDocument / form / signaturePresent），
   加载顺序敏感；无测试、无 CI；schemaVersion 常量写了但从未校验。
5. 手写/宋体依赖 Kaiti SC、Songti SC，Windows/Android 会回退，跨设备版式会漂。

## 第六轮：导师筛选不出名字的修复（teacherName 独立字段）

1. `initialRecord` 增加 `teacherName:''` 独立字段；保存时（workspace.js save() 和 batch.js

   文字/图片/画笔哪种模式，只要在「导师签名-输入姓名」框里打过名字就存。
2. `cleanRecord` 对旧记录兼容：无 teacherName 时回填 mentor.text，并按 ≤24 字校验。

4. **旧记录需手动补**：打开记录 → 在导师签名「输入姓名」框填名字 → 保存一次即可（文字在
